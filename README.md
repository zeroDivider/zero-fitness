# zero-fitness

[![Android](https://img.shields.io/badge/platform-Android-3DDC84?logo=android&logoColor=white)](#)
[![Kotlin](https://img.shields.io/badge/language-Kotlin-7F52FF?logo=kotlin&logoColor=white)](#)
[![Jetpack Compose](https://img.shields.io/badge/UI-Jetpack%20Compose-4285F4?logo=jetpackcompose&logoColor=white)](#)

`zero-fitness` is an Android fitness app focused on building a clean, practical training experience. The current version centers on the exercise library: creating exercises, editing details, searching, filtering, and syncing exercise data.

This repository is also part of my public portfolio. It shows how I work when a project is still growing: small slices, visible progress, readable implementation, and honest notes about what is done versus what comes next. 🙂

Active work is tracked on the [project board](https://github.com/users/zeroDivider/projects/2/views/1). The full plan lives in [`docs/ROADMAP.md`](docs/ROADMAP.md).

| Product area | Status | Notes |
|---|---|---|
